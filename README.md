# Folkets Hus Vaggeryd - Webbplats & Bokningssystem

Webbplats och administrationssystem för Folkets Hus i Vaggeryd. Plattformen hanterar presentation av verksamheten, aktuella biovisningar, kommande evenemang samt ett interaktivt lokalgalleri.

## Funktioner

- **Bioprogram:** Dynamisk visning och hantering av filmer och speltider.
- **Evenemang:** Hantering och presentation av kommande kultur- och föreningsarrangemang.
- **Lokalgalleri:** Sorterbart galleri för lokaler med stöd för drag-and-drop-omordning.
- **Administrationspanel:** Lösenordsskyddat administrationsgränssnitt för innehållshantering.
- **Reverse Proxy:** Konfigurerad för Apache/LiteSpeed (.htaccess) och Node.js Express.

## Teknikstack

- **Frontend:** HTML5, CSS3, JavaScript, SortableJS
- **Backend:** Node.js, Express
- **Autentisering:** express-basic-auth
- **Datalagring:** JSON-baserad lagring
